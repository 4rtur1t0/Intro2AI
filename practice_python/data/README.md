# Datos de la práctica 1

- `iris.csv`: las 150 flores de Fisher (1936): cuatro medidas en cm (`largo_sepalo`,
  `ancho_sepalo`, `largo_petalo`, `ancho_petalo`) y la especie (`setosa`, `versicolor`
  o `virginica`), 50 flores de cada una. La primera fila es la cabecera. Es el mismo
  conjunto que devuelve `sklearn.datasets.load_iris()`.
